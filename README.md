# 项目公告

ONES Open Platform 1.0 团队插件。目标环境：ONES v7.18.2。

## 功能

- 项目管理员可按需添加「项目公告」组件。
- 项目成员创建草稿、发布、撤回、编辑和置顶公告；管理操作仅限创建者。
- 公告可面向全项目或指定成员，支持富文本与 HTTPS 外部附件链接。
- 「公告中心」在个人工作台聚合跨项目公告，支持项目、已读状态和标题筛选。
- 打开公告详情即标记已读，创建者可查看阅读统计。

## 开发

```bash
pnpm install
pnpm test
pnpm typecheck
pnpm format:manifest
pnpm packup
```

修改 `config/plugin.yaml` 后，本地调试前执行 `pnpm clear`。本地调试需先完成 `op login` 与 `op pickteam local`。

## 安全边界

- 后端身份只信任 ONES 网关注入的 `Ones-User-Id`。
- v1.0.0 使用安全降级权限：项目成员可创建公告，仅创建者可管理自己的公告。
- 定向公告在后端执行受众过滤；不可见公告统一返回 404。
- 富文本在后端进行白名单清洗；附件只接受 HTTPS 链接，不存储文件内容。

## 发布

插件为团队级 `simple` 策略，安装后不可切换插件类型或策略。发布产物必须使用版本化名称：`项目公告-v1.0.0.opk`。
